# Student Marks Management System

## Project Description

The Student Marks Management System is a Python-based project used to store and manage student marks.

The program stores student records in a CSV file and calculates total marks, percentage and grade.

## Features

- Add student records
- View all students
- Search student by roll number
- Calculate total marks
- Calculate percentage
- Assign grades
- Display class summary
- Store data using CSV file

## Technologies Used

- Python
- CSV File Handling

## Subjects

- Python
- Maths
- English
